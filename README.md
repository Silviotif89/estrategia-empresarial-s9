# Estrategia Empresarial · Sesión 9

Presentación web para impartir la sesión universitaria de ADM0406, Grupo 12, Universidad Americana. El tema es **Evaluación externa y análisis competitivo** (jueves 15 de octubre de 2026). La secuencia prioriza la enseñanza y la aplicación guiada.

## Abrir y publicar

Es un sitio estático, sin dependencias ni inicio de sesión. Abrí `index.html` en un navegador o publicá el contenido de esta carpeta en la raíz del repositorio `estrategia-empresarial-s9` y activá GitHub Pages.

## Qué incluye

- 45 diapositivas en seis bloques académicos, con navegación, índice, pantalla completa y notas de facilitación.
- Cinco juegos didácticos: ahorcado, completar oraciones, rompecabezas de Porter, ordenar etapas y verdadero o falso. Cada actividad aparece después de explicar los conceptos relacionados.
- Elementos de enseñanza interactivos: tarjetas de explicación progresiva, explorador PESTEL, diagrama seleccionable de Porter, contraste entre oportunidad y amenaza, matriz editable por pasos y descarga CSV.
- Temporizador diario hasta las 7:00 p. m. en `America/Managua`, independiente de la navegación y las actividades.
- Diseño adaptable para proyección 16:9, pantalla pequeña y controles táctiles.

## Contenido y cuidado académico

El contenido toma como base la presentación S9 y el sílabo del curso. Café Segovia y los ejemplos señalados como didácticos son ficticios. No se presentan cifras de mercado de Nicaragua. Las O/T son provisionales y requieren evidencia verificable.

Las referencias académicas están disponibles desde el botón “Fuentes” en la presentación. Las matrices y ejemplos numéricos hipotéticos se identifican como material didáctico, no como datos de mercado. El sitio no envía respuestas ni datos a servicios externos; solo abre enlaces de referencia cuando el visitante los selecciona.
